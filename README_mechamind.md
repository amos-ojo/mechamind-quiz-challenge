# MechaMind Quiz Challenge

**An interactive 10-question multiple-choice quiz application built with
Python.**

## About the Project

MechaMind Quiz Challenge is a command-line quiz application developed
for the **CTE213** course assignment. It assesses introductory knowledge
of mechatronics, electronics, programming, engineering principles, and
control systems.

The application presents 10 multiple-choice questions in a randomized
order. After each response, it indicates whether the answer is correct
and provides an explanation.

## Features

-   10 multiple-choice questions.
-   Randomized question order on each attempt.
-   Accepts answers **A, B, C, or D**, regardless of letter case.
-   Checks user input and requests a valid choice when necessary.
-   Awards **10 marks** per correct answer, for a total of **100
    marks**.
-   Displays the final score and grade.
-   Shows the number of correct and incorrect answers.
-   Provides a revision summary of questions answered incorrectly.
-   Allows the user to take the quiz again.

## Requirements

-   Python 3
-   No third-party packages are required. The program uses Python's
    built-in `random` module.

## How to Run

1.  Download or clone this repository.

2.  Open a terminal or command prompt in the project directory.

3.  Run the program:

    ``` bash
    python mechamind_quiz_challenge_ojo_amos.py
    ```

    If your system uses `python3`, run:

    ``` bash
    python3 mechamind_quiz_challenge_ojo_amos.py
    ```

4.  Press **Enter** when prompted to begin.

5.  Answer each question with **A**, **B**, **C**, or **D**.

6.  Review your score, grade, and revision summary at the end.

## Grading System

  Score      Grade
  ---------- -----------------------
  80--100    A - Excellent
  70--79     B - Very Good
  60--69     C - Good
  50--59     D - Pass
  Below 50   F - Needs Improvement

Each correct answer is worth 10 marks.

## Topics Covered

The quiz includes introductory questions about:

-   Mechatronics and integrated engineering systems
-   Sensors and actuators
-   Programmable Logic Controllers (PLCs)
-   Python output
-   Force and its SI unit
-   Electronic components, including diodes
-   Closed-loop control systems
-   Computer-Aided Design (CAD)
-   Electrical current measurement
